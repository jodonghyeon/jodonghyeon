## Hi, I'm Donghyeon Jo

I'm a Computer Science student at DigiPen Institute of Technology, studying Real-Time Interactive Simulation. Based in Redmond, Washington, I build real-time graphics and interactive projects, primarily with C++, OpenGL, and GLSL.

I'm especially interested in graphics engineering, extended reality (XR), and computer vision.
